# Cute Badge Background Studio v1.1

293 × 164 px 썸네일용 배경 도형·스탬프 제작 웹앱입니다. 빌드 과정 없이 정적 파일만으로 실행되며 GitHub Pages와 Cloudflare Pages에 그대로 업로드할 수 있습니다.

## v1.1 변경 사항

- 미리보기의 기본 점선 안내선을 제거했습니다. `안전영역 안내선`은 기본 OFF이며 저장 파일에는 포함되지 않습니다.
- 선택 박스는 점선 대신 실선으로 변경했습니다.
- 다중 획 색상 변경이 즉시 반영되도록 이벤트 처리와 획 렌더링 방식을 수정했습니다.
- 다중 획은 `바깥쪽 → 안쪽` 순서가 확실히 보이도록 각 행의 두께를 독립적인 띠 두께로 계산합니다.
- 배경 프리셋의 한국어 표시와 폰트 스택을 정리했습니다.
- 왼쪽 UI 폭을 넓혔습니다.
- 도형·스탬프·점선 펜 선택 시 미리보기에서 8개 크기 조절 손잡이와 회전 손잡이를 사용합니다.
- Shift + 모서리 드래그로 원래 비율을 유지합니다.
- 스탬프는 에셋을 클릭하면 `찍기 모드`가 되며 색상, 외곽선, 두께, 크기, 회전을 먼저 정한 뒤 캔버스 클릭 위치에 반복해서 찍습니다.
- 스탬프 찍기 위치에 반투명 미리보기(고스트)를 표시합니다.
- 사람 손으로 그린 느낌의 도형 8종을 추가했습니다: 손그림 블롭, 손그림 네모, 붓 구름, 삐뚤 타원, 물결 배지, 손그림 하트, 찢은 라벨, 말랑 패널.
- 스탬프 8종을 추가했습니다: 리본, 미니 하트, 십자 반짝, 물결선, 잎사귀, 빙글선, 물방울, 꽃잎.
- 참고 이미지에서 자주 보이는 `안쪽 스티치/점선 테두리`, `부드러운 그림자`, `미니 하트`, `작은 색종이 선` 패턴을 추가했습니다.
- 점선 펜 오브젝트도 선택 후 색상·두께·점 길이·간격을 다시 수정할 수 있습니다.
- v1.0 프로젝트 JSON을 불러와도 새 속성이 자동 보완됩니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 브라우저 보안 설정에 따라 로컬 파일에서 일부 저장 동작이 제한되면 간단한 로컬 서버로 열어 주세요.

```bash
python -m http.server 8000
```

그 후 `http://localhost:8000`으로 접속합니다.

## GitHub Pages

1. 이 폴더의 파일을 저장소 루트에 업로드합니다.
2. GitHub 저장소의 `Settings → Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. `main / (root)`를 선택하고 저장합니다.

`.nojekyll` 파일이 포함되어 있습니다.

## Cloudflare Pages

- Framework preset: `None`
- Build command: 비워두기
- Build output directory: `/` 또는 저장소 루트

정적 HTML/CSS/JavaScript만 사용하므로 별도 npm 설치가 필요하지 않습니다.
