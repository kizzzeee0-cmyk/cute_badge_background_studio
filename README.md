# Cute Badge Background Studio v1.4

293×164 배지/썸네일 배경 제작용 단일 HTML 앱입니다.
정적 웹앱이라 브라우저에서 바로 열거나 GitHub Pages / Cloudflare Pages에 업로드해 사용할 수 있습니다.

## v1.4 업데이트
- 꼬불선 / 컨페티 스탬프 경로 보정
- 내부 포인트 패턴 최소 크기 확장 (아주 작게 설정 가능)
- 도형/스탬프 내부 전용 **클리핑 포인트 펜** 추가
- 포인트 펜 흔적을 부드럽게 일부 지우는 **페이드 지우개** 추가
- 여러 수치 조절 UI를 **슬라이더(막대 바)** 중심으로 변경
- 첨부 이미지에 적용하는 **부드러운 그림자** 섹션 추가
  - 색상 / 투명도 / 방향 각도 / 거리 / 흐림 조절 가능
- 기존 페이지 다중 관리 + PNG 일괄 ZIP 저장 유지

## 실행 방법
1. 압축 해제
2. `index.html`을 브라우저에서 열기
3. 또는 폴더 전체를 GitHub Pages / Cloudflare Pages에 업로드

## 주요 파일
- `index.html` : 메인 UI
- `style.css` : 스타일
- `app.js` : 기능 로직
