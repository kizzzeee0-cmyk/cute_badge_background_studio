# Cute Badge Background Studio v1.5

293×164 배지/썸네일 배경 제작용 단일 HTML 앱입니다.
정적 웹앱이라 브라우저에서 바로 열거나 GitHub Pages / Cloudflare Pages에 업로드해 사용할 수 있습니다.

## v1.5 업데이트
- 다중 획 두께를 **슬라이더 + 숫자 직접 입력칸** 둘 다 지원
- 다중 획 두께를 **0.1 단위**로 세밀하게 조절 가능
- 도형 / 스탬프용 **외곽 글로우 / 번짐 효과** 추가
  - 색상 / 투명도 / 번짐 두께 / 흐림 조절 가능
- 기존 v1.4 기능 유지
  - 페이지 여러 장 관리
  - 포인트 펜 / 페이드 지우개
  - 이미지 그림자
  - 모든 페이지 PNG ZIP 저장

## 실행 방법
1. 압축 해제
2. `index.html`을 브라우저에서 열기
3. 또는 폴더 전체를 GitHub Pages / Cloudflare Pages에 업로드

## 주요 파일
- `index.html` : 메인 UI
- `style.css` : 스타일
- `app.js` : 기능 로직
