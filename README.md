# Cute Badge Background Studio v1.6

293×164 배지/썸네일 배경 제작용 단일 HTML 앱입니다.
정적 웹앱이라 브라우저에서 바로 열거나 GitHub Pages / Cloudflare Pages에 업로드해 사용할 수 있습니다.

## v1.6 업데이트
- 내부 포인트 패턴(땡땡이 / 별 / 하트 / 컨페티 등) 크기를 **이전보다 훨씬 더 작게** 설정 가능
- 내부 포인트 패턴 **밀도 조절** 추가
  - 더 촘촘하게 배치해서 갯수를 많이 늘릴 수 있음
- 도형 이동 시 **캔버스 중앙 스냅** 추가
  - 중앙에 가까워지면 자동으로 중앙 정렬
  - 가이드 라인 표시
- 빠른 정렬에 **정중앙 버튼** 추가

## 실행 방법
1. 압축 해제
2. `index.html`을 브라우저에서 열기
3. 또는 폴더 전체를 GitHub Pages / Cloudflare Pages에 업로드

## 주요 파일
- `index.html` : 메인 UI
- `style.css` : 스타일
- `app.js` : 기능 로직
