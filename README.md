# Cute Badge Background Studio v1.2

293×164 배지/썸네일 배경 제작용 단일 HTML 앱입니다.

## v1.2 주요 업데이트
- 페이지 추가 / 복제 / 삭제
- 모든 페이지 PNG 일괄 ZIP 저장
- 이미지 첨부 및 위치/크기 조절
- 안쪽 스티치 점선의 위치/배율 개별 조절
- 내부 포인트 패턴 크기 / 간격 / 영역 / 블러 조절
- 패턴 찌그러짐 완화
- 손그림 느낌 프리셋 교체 및 같은 프리셋 재클릭 토글 해제
- 꼬불선 / 축하 컨페티 스탬프 추가
- 좌측 UI 폭 확장
- 다중 획 색상 실시간 반영 로직 정리
- 외곽선 소프트 / 질감 옵션 추가

## 실행 방법
1. 압축 해제
2. `index.html` 파일을 브라우저에서 열기
3. 필요 시 정적 서버로 실행

## 파일 구성
- `index.html` : 메인 UI
- `style.css` : 스타일
- `app.js` : 기능 로직
