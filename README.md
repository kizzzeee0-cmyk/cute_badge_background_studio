# Cute Badge Background Studio v1.9

293×164 배지/썸네일 배경 제작용 단일 HTML 앱입니다.
정적 웹앱이라 브라우저에서 바로 열거나 GitHub Pages / Cloudflare Pages에 업로드해 사용할 수 있습니다.

## v1.9 업데이트
- 손떨림 보정 기본 적용 **그림 그리기 도구** 추가
- 그리기 보정 방식 선택 가능
  - 부드러운 곡선 보정
  - 선형 보정
  - 강한 곡선 보정
- 원하는 색상과 두께로 자유롭게 그림 그리기 가능
- **그린 그림에도 다중 획 적용 가능**
- **불러온 사진에도 다중 획 적용 가능**
- 다중 획은 기본적으로 **최소 2겹** 구조 제공
- 그림을 선택된 사진의 **위 / 아래 레이어**로 그릴 수 있음
- 사진을 선택한 상태에서 그리면 해당 그림이 사진에 자동 연결되어 **사진과 함께 이동**
- 기존 레이어 위/아래 이동 버튼 유지

## 실행 방법
1. 압축 해제
2. `index.html`을 브라우저에서 열기
3. 또는 폴더 전체를 GitHub Pages / Cloudflare Pages에 업로드
