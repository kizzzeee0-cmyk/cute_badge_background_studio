# Cute Badge Background Studio v1.3

293×164 배지/썸네일 배경 제작용 단일 HTML 앱입니다.
GitHub Pages / Cloudflare Pages 업로드용 정적 웹앱 형태입니다.

## v1.3 주요 업데이트
- 안쪽 스티치 점선 테두리를 **미리보기 화면에서 직접 드래그/리사이즈** 가능
- 내부 포인트 패턴의 **찌그러짐 완화**
- 패턴 **크기 최소 범위 확장 / 간격 범위 확장**
- 패턴 **영역 위치 / 영역 크기 조절** 강화
- 패턴의 **첫 줄만 방향 지정 블러** 기능 추가
- 꼬불선 스탬프 디자인 보강
- 축하 컨페티 스탬프 보강
- 페이지 여러 장 제작 + **PNG 일괄 ZIP 저장**
- 이미지 첨부 및 위치/크기 조절
- 외곽선이 없어도 밋밋하지 않게 보이는 **가장자리 번짐(soft bleed)** 강화

## 실행 방법
1. 압축 해제
2. `index.html`을 브라우저에서 열기
3. 또는 GitHub Pages / Cloudflare Pages에 그대로 업로드

## 파일 구성
- `index.html` : 메인 UI
- `style.css` : 스타일
- `app.js` : 기능 로직
